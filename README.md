# 猛练豚 (CapyFit)

> **让健身像卡皮巴拉一样稳定而有趣。**  
> **Make your fitness journey as steady and chill as a Capybara.**

猛练豚是一款基于 Flutter 开发的治愈系健身应用。它摒弃了传统健身软件的严肃感，采用独具特色的**手绘视觉风格**和**卡皮巴拉（Capybara）**主题，旨在为用户提供一个轻松、无压力的运动记录与饮食管理环境。

### ✨ 项目特色 (Key Features)

- 🎨 **独特视觉**：全手绘 UI 设计，告别枯燥。 (Unique hand-drawn UI aesthetic)
- 🦦 **卡皮巴拉伴跑**：可爱的卡皮巴拉元素陪伴你的训练。 (Adorable Capybara-themed motivation)
- 🏋️ **训练计划**：轻松创建并追踪每日健身任务。 (Seamless workout tracking & planning)
- 🥗 **饮食库**：内置丰富的食物营养数据，科学管理摄入。 (Comprehensive diet & nutrition library)
- 📊 **成长足迹**：直观展示训练时长、热量消耗与打卡记录。 (Intuitive stats & progress tracking)
